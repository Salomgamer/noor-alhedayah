## 🌟 نبذة عن المشروع / Overview

**نور الهداية** هو تطبيق ويب إسلامي متكامل وحديث يجمع أهم مصادر العلم والعبادة في واجهة عربية أنيقة وسريعة، تعمل دون إنترنت (Offline-First) وتتوافق مع جميع الأجهزة والهواتف الذكية.

### ✨ المميزات الرئيسية / Features
- 📖 **القرآن الكريم كاملاً**: قراءة وتفسير واستماع بأصوات نخبة من كبار القرّاء.
- 📚 **السنة النبوية الشريفة**: كتب الحديث المعتمدة مع البحث والتصفح الميسر.
- 🕌 **مواقيت الصلاة**: حساب دقيق لمواقيت الصلاة حسب موقعك الجغرافي.
- 🧭 **اتجاه القبلة**: بوصلة بصرية دقيقة لتحديد القبلة نحو الكعبة المشرفة.
- 🕋 **المساجد القريبة**: خريطة تفاعلية لعرض المساجد حولك مع دعم العمل دون إنترنت.
- 🤲 **الأذكار والأدعية**: أذكار الصباح والمساء، أدعية مأثورة، ومسبحة رقمية ذكية.
- 🧪 **اختبر حفظك وتسميع**: أدوات حديثة لتتبع الحفظ واختبار الذاكرة والتسميع الصوتي.
- 🖼️ **بطاقات دعوية**: صانع بطاقات إسلامية جاهزة للمشاركة والنشر.
- 💎 **أيقونات متجهة عالية الدقة (High Quality SVG)**: تصميم نظيف لجميع الأيقونات بملفات SVG متجهة متجاوبة وسريعة.

## 🚀 التشغيل المحلي / Local Setup

يمكنك تشغيل المشروع محلياً بسهولة باستخدام أي خادم ويب بسيط:

```bash
# باستخدام Python
python -m http.server 8080

# أو باستخدام Node.js (npx serve)
npx serve .
```

ثم افتح المتصفح على: `http://localhost:8080`
